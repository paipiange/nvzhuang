# nvzhuang 移动端 UI 原型

来源项目：https://github.com/paipiange/nvzhuang

## 文件说明
- `nvzhuang-ui.html`：单文件、可离线打开的 4 屏交互式 UI 设计稿，无需安装依赖。
- `nvzhuang-ui-preview.png`：四屏并排静态预览。

## 视觉方案
- 风格：轻时尚杂志、奶油白底、玫瑰粉按钮，保持内容为主。
- 页面：发现穿搭 / 探索图库 / AI 试衣间 / 我的衣橱。
- 主要色：`#fcfbfa` / `#cd7188` / `#272225` / `#f4f1f0`。
- 产品建议：游客可以先浏览图库。试穿入口突出，可自备人像或从 AI 模特图库中选择；高级模型配置折叠到设置页。

## 可试交互
- 底部导航页签切换（各手机均可独立切换）
- 图库搜索、分类、收藏、服装详情
- 服装卡片 → “穿上这件” → AI 试衣间
- 试衣间模型选择和结果样式演示
- 我的页面设置 / 收藏 / 历史弹层

**注意：**原型使用自绘矢量服装和模特示意插画，不是真实生成效果，不调用后端或模型，也不上传照片，按钮的动作属于交互模拟。浏览器打开 HTML 时可以直接体验。

## 开发落地
- 兼容目标：微信小程序、Android / iOS App，推荐 UniApp + Vue 3 共用大部分页面与组件。
- 服务端：复用仓库 `backend/` 的 GoFrame v2 试衣服务；图库与模型的数据接口需要按正式产品的数据结构封装。
- 正式版首先完成：服装列表/筛选、试衣输入与生成结果、收藏/历史、用户知情同意与数据删除。
- 含试衣的公开服务必须有身份认证、限流、额度/成本控制；密钥应保存在服务端或受保护的个人配置区，不应硬编码到 App/小程序。
- 微信小程序还需适配安全区、登录授权、备案/审核要求、订阅和支付能力（如计划商业化）。
- README 的「图库浏览免费」与「AI 换装需后端/模型」需要在产品中明确区分。
