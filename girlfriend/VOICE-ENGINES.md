# 本机语音 / 豆包语音：实际使用

## 先启动两个窗口

1. 安装 Go 和 Node.js 24+。在本目录双击 `start-voice-backend.bat`，保留窗口。它从源码启动 Go 后端，监听 `127.0.0.1:8000`，使用同目录的 `voice-backend.example.yaml`。此模板仅面向当前电脑，不对公网开放，也不包含 Key。
2. 双击 `start.bat`，打开 `http://127.0.0.1:8787`。保留此窗口。

端口已被当前项目服务使用时直接打开页面，不要重复启动第二个后端。若另一个程序占用了端口，先确认占用者再处理；启动失败不会被报告为成功。

这两个启动器不会自动下载大型模型。只用豆包模式时，不需要运行本机 Qwen、FunASR 或 CosyVoice。选择本机模式时，需先按后端本地部署说明启动这三套服务。

## 本机模式

1. 页面右上角设置 → **本机语音（Qwen + FunASR + CosyVoice）**。
2. 后端地址保持 `http://127.0.0.1:8000`，保存。
3. 可以输入文字；也可点击 **语音**，允许麦克风后说话，再点击 **结束录音**。
4. 显示识别文字、模型回复并播放 WAV。点击 **打断** 可停止；**清空本机 Qwen 会话记忆** 清空连接记忆。

本机模式不需要云端聊天 Key 或豆包 Key。模型服务默认在 8080、10096、50000；语音模型及缓存根目录默认 `D:/ai/ai/nvzhuang`。后端启动模板中的 `voice.root` 应与实际部署一致。

## 豆包语音大模型 3.0

1. 在豆包语音控制台开通 **Seeduplex 3.0** 权限并取得语音 API Key。火山方舟的文字模型 Key 不代表已开通这项服务。
2. 页面设置 → **豆包语音大模型 3.0（Seeduplex）**。
3. 后端地址保持本机地址，先点击 **检查语音连接**；后端未配置 Key 时，在下方填入 **豆包语音 API Key** 并保存。检查不会验证账号权限或发送该 Key；真实权限在开始通话时确认。
4. 推荐点击 **开始通话**。页面确认 `streaming:true` 及当前角色后才申请麦克风，持续发送 16 kHz / 20ms PCM，并直接播放 24 kHz PCM。每轮由上游 VAD 分开，无需点击结束录音。
5. AI 说话时直接插话，或点 **停止当前回复**，均立即清空旧播放并取消旧生成；点 **结束通话** 关闭麦克风和连接。
6. 不支持 AudioWorklet 的设备会明确提示，可用 **按轮语音**，说完点击 **结束录音**；此模式继续播放 WAV 分段。**新建豆包语音会话** 会断开旧会话，下一次重新连接；页面聊天记录保留。

当前客户端支持免提持续通话，并保留独立的按轮录音入口。豆包模式不接受普通文字输入；切到本机或云端文字模式可文字聊天。不会把指定文字朗读接口当成语音模型的聊天回复。

豆包 Key 仅保存在当前页面运行内存，刷新或关闭页面后清空；启动时会主动移除旧版本曾写入 `localStorage` 的语音 Key。Key 通过同源本机 WebSocket 传给当前后端会话；后端只在内存中使用，不写入配置文件、数据库或日志。Key 只能发给代码固定的官方安全 WSS 端点，页面不能修改上游地址。

也可不给页面填写 Key，改由**启动后端之前的进程环境变量**提供 `SEEDUPLEX_API_KEY`，兼容 `VOLCENGINE_REALTIME_API_KEY`。页面填写值优先；“移除本机 Key”只删除浏览器保存值，不会移除服务端环境变量。模型固定为当前官方 JSON 协议的 `1.2.6.1`。

## 角色与音色

在工作室选择知夏或林溪会关闭旧语音连接，下次发言重新建会话；本机浏览器按角色分别保留历史，不把旧角色历史交给新角色。语音识别后的整句“切换到林溪”同样可切换。浏览器不能指定任意上游音色，仅能选择预设角色：

- **豆包**：知夏优先使用 `SEEDUPLEX_VOICE_ZHIXIA`，可兼容原 `SEEDUPLEX_VOICE`，两者皆未设置时默认 `zh_female_vv_jupiter_bigtts`；林溪使用 `SEEDUPLEX_VOICE_LINXI`。填写账号被授权使用的音色 ID，修改后重启后端。
- **本机 CosyVoice**：知夏默认 `local-reference`，可用 `VOICE_LOCAL_ZHIXIA` 映射已注册音色；给 CosyVoice 进程配置有授权的 `COSYVOICE_LINXI_REFERENCE_WAV` 和对应准确逐字稿 `COSYVOICE_LINXI_REFERENCE_TEXT`，并给 Go 进程设置 `VOICE_LOCAL_LINXI=linxi-reference`。重启两个进程后再选择林溪。
- **未配置**：林溪没有对应音色时会拒绝启动语音会话，不会顶替成知夏音色；可切回知夏或继续使用独立的云端文字模式。

本页和 UniApp 的 H5 语音页均提供豆包全双工模式，并保留旧按轮入口。写真是独立请求，开启或取消写真都不会关闭麦克风或清空语音记忆。静态头像的说话视觉反馈不是真实的口型同步。

## UniApp H5 持续通话

在 UniApp 的「我的 → AI 陪伴通话」页选择 **豆包 SeedDuplex 3.0**，点击 **开始通话 · 持续开麦**。可以在 UniApp 设置页为当前运行会话输入语音 Key，也可以由后端进程配置 `SEEDUPLEX_API_KEY`；UniApp 与独立工作室互不复用内存中的 Key。一次开始后持续传送 16 kHz / 20 ms PCM，不需要每轮结束录音；上游 VAD 分轮，识别和回复字幕实时更新。AI 说话期间可以直接插话，也可点 **停止当前回复**；点 **结束通话** 释放麦克风和连接。**清空通话记忆** 会重建上游并重新确认能力。

请通过安全浏览器来源使用，允许麦克风权限。建议佩戴耳机；扬声器效果取决于系统回声消除。设备缺少 AudioWorklet 或 App 尚无持续 PCM 回调时，页面明确提示不支持免提并保留按轮录音。网络持续拥塞超过约 3 秒会停止通话，需手动重新连接；不会自动重试付费语音或生图。通话中可切换清单内头像、服装与姿势并独立生成/取消高清写真；切换角色身份则结束旧通话，重新开始以应用新的人设和音色。

## 连接与故障定位

- **缺 Key**：在页面设置填入语音 Key，或重启已注入环境变量的后端。
- **权限或音色失败**：确认语音控制台开通的是 Seeduplex 3.0，余额/配额和所选音色权限可用。
- **一直无法连接**：后端必须能连接 `wss://openspeech.bytedance.com/api/v3/duplex/realtime/dialogue`；浏览器页面自己的 FLClash 设置不会自动改变 Go 后端网络。若 Go 后端需代理，在启动该进程前配置其网络环境。
- **麦克风拒绝**：在浏览器为回环页面允许麦克风；设备被占用时关闭占用程序再试。
- **听不到声音**：检查自动朗读开关、浏览器自动播放限制及系统输出设备。可通过历史回复的“朗读”使用浏览器音色再次听文字，但不是重新请求豆包合成。
- **录音长时间等待**：录音在结束后按真实时长上传。例如 20 秒录音需要约 20 秒上传，再加模型回复时间；可随时打断。单轮上限约 64 秒 / 2 MiB。
- **切换引擎**：保存设置会取消旧活动任务并断开旧连接。不会静默降级到另一个付费服务。

豆包录音会发送到服务商并产生用量，取消不保证服务商未计费。开启时请使用自己的声音或有权使用的录音。新建会话不代表删除服务商保留的数据。
