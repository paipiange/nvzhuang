# AI 女友 · 第三批 30 轮完善与验收

本批按“本机优先、豆包语音可选、明确显示真实连接状态”继续迭代。30 项中包含代码修复和回归核查，不代表 30 个独立新功能。未新增依赖；本机 Qwen、CosyVoice 链路做了实际请求；没有使用真实豆包 Key 或发起付费云端语音调用。

## 1–10：本机优先和引擎切换

- [x] **第 1 轮：首次进入本机模式。** 即使浏览器留有旧云端聊天配置、但没有用户明确保存引擎选择，新会话仍默认本机；新增回归测试。
- [x] **第 2 轮：尊重显式偏好。** 用户已保存的 `remote` 选择继续生效，不被默认值覆盖；新增回归测试。
- [x] **第 3 轮：无效偏好安全回退。** 损坏或未知模式仍回到本机，已有存储恢复测试通过。
- [x] **第 4 轮：本机无云端聊天 Key。** 本机模式可保存并开始文字聊天，无需云端文字 Key。
- [x] **第 5 轮：云端切换仍明确。** 只有主动选择云端文字模式才要求 API 地址、模型名和 Key。
- [x] **第 6 轮：切换时取消旧请求。** 云端请求进行中切到本机，迟到的远端回复不会写入新对话。
- [x] **第 7 轮：本机入口隔离。** 本机聊天只连接本机语音 WebSocket，不经云端文字聊天代理。
- [x] **第 8 轮：本机地址限制。** 仅接受无凭据的 localhost / 回环地址；外部地址和带查询凭据的目标被拒绝。
- [x] **第 9 轮：跨源防护。** 非同源页面不能借用本机代理发送模型请求。
- [x] **第 10 轮：连接状态不夸大。** 本机 WebSocket 建立只标记“本机后端已连接”，并提示模型健康将在发言时验证；不会把 `session.ready` 冒充为 Qwen/ASR/TTS 健康证明。

## 11–20：文字、回合、录音和播放

- [x] **第 11 轮：握手格式边界。** 非标准 WebSocket 版本或握手 Key 被拒绝；正常回环握手测试通过。
- [x] **第 12 轮：连接失败恢复。** 后端不可达或握手报错后恢复输入，下一轮可重新连接。
- [x] **第 13 轮：中文长度计数。** 本机文字输入按 Unicode 字符限制；2000 字边界可用，超限发送前拒绝。
- [x] **第 14 轮：旧连接隔离。** 旧 WebSocket 的迟到 close 或回包不覆盖新会话。
- [x] **第 15 轮：打断回合。** 打断会停止本轮，迟到文字不会写入历史，输入立即可继续。
- [x] **第 16 轮：清空记忆超时。** 未收到 reset 确认时丢弃状态不确定的连接；下一轮建立新连接。
- [x] **第 17 轮：短录音与静音。** 过短或近乎数字静音的录音不会发给识别模型。
- [x] **第 18 轮：麦克风权限失败。** 拒绝授权或音频初始化失败后释放设备资源，仍可使用文字聊天。
- [x] **第 19 轮：音频段校验。** 拒绝分段外二进制、重叠段、空段及未结束的音频段。
- [x] **第 20 轮：播放生命周期。** WAV 分段按序播放；取消、关闭自动朗读和迟到播放回调不会泄漏对象 URL 或干扰新回合。

## 21–30：模型质量、豆包链路及最终回归

- [x] **第 21 轮：真实本机文字链路。** 经运行中的 GoFrame WebSocket → Qwen 完成输入和回复，返回有效文字。
- [x] **第 22 轮：角色提示词实测。** 以中文安慰类输入检查模型回复；实际回复为中文、简洁且符合陪伴语气。
- [x] **第 23 轮：本机语音输出实测。** Qwen/CosyVoice 实际返回 4 段 WAV，共 78,896 字节；WAV 容器和 24 kHz 采样率检查通过。
- [x] **第 24 轮：本机组件健康状态。** 运行时状态接口报告 Qwen、FunASR、CosyVoice 服务可用，模型关键文件检查达到 100%。该检查不等同于完整权重哈希校验。
- [x] **第 25 轮：豆包缺 Key。** 未配置时明确报错，不申请麦克风、不假装连接成功。
- [x] **第 26 轮：豆包 Key 隔离。** Key 只随豆包会话握手发送；切回本机不带上该 Key。
- [x] **第 27 轮：豆包会话操作。** 取消与新建会话的模拟上游回归通过；页面历史保留，不会把会话 reset 伪装为删除服务商数据。
- [x] **第 28 轮：豆包转写兜底。** 当最终转写事件没有完整 `transcript` 字段时，使用受限长度的累计 delta 生成最终字幕；空结果和超长结果明确失败。新增 Go 回归测试。
- [x] **第 29 轮：代理环境。** 豆包 WebSocket Dialer 现在使用 Go 进程的标准代理环境配置；代码路径已核查。未用真实豆包服务验证代理、Key 权限或计费行为。
- [x] **第 30 轮：全量回归。** `node --test girlfriend/app.test.mjs`（69 项）、`node --test girlfriend/server.test.mjs`（21 项）、`go test ./...`、`go vet ./...` 及 `git diff --check` 均通过。
