# 知夏 · AI 虚拟女友

这是仓库里的 AI 角色工作室：支持**本机语音（Qwen + FunASR + CosyVoice）**、**豆包语音大模型 3.0（Seeduplex）**和独立的云端文字聊天。在 1,499 位本地 AI 模特中挑选头像、2,727 套穿搭中选衣服，选姿势后可调用自己的图像模型生成形象。

要使用语音，请先看 [本机 / 豆包语音操作说明](./VOICE-ENGINES.md)：双击 `start-voice-backend.bat` 启动后端，再双击 `start.bat` 打开页面。首次打开默认使用本机模式；旧聊天配置中的云端 Key 不会让应用自动切换到云端，已手动保存的引擎选择仍会沿用。豆包语音需手动切换并配置。豆包 Key 可直接填在本机页面，不要发送到聊天。豆包模式提供 **开始通话** 持续开麦和 **按轮语音** 两种入口；持续通话需要支持 AudioWorklet 的浏览器。真实豆包账号尚待有权限的 Key 验收，不能将模拟协议测试当作云端实录成功。

## 启动

Windows 需安装 **Node.js 24 或更新版本**，无需安装 npm 依赖。项目根据你已配置的 FLClash 默认 HTTP 代理 `127.0.0.1:7890` 发起模型网络请求：

- 语音后端：先双击 `start-voice-backend.bat`（需要 Go），仅监听本机 8000，保留窗口；本机三套模型另按部署说明启动，豆包模式不需要这些模型。
- 页面：双击 `start.bat`（需要 Node.js 24+），按提示等待服务启动。
- PowerShell：进入 `girlfriend` 目录后，先给当前终端配置 FLClash 地址，再启用 Node 内置环境代理：

```powershell
$env:HTTP_PROXY = 'http://127.0.0.1:7890'
$env:HTTPS_PROXY = 'http://127.0.0.1:7890'
$env:NO_PROXY = 'localhost,127.0.0.1,::1'
node --use-env-proxy server.mjs
```

需要指定端口时，在启动前运行 `$env:PORT = '8788'`。也可以把 `HTTP_PROXY`/`HTTPS_PROXY` 换成自己的本机代理地址；要让系统代理生效，必须在 `node --use-env-proxy` 启动前设置环境变量。
FLClash 仅转发互联网流量；页面、Key、聊天记录、图库图片和图像预览均保留在本机。网络请求会发送给你选择的模型服务商。

## 聊天、换头像、换装与姿势

本机模式不需要云端聊天 Key：在设置中选择 **本机 Qwen + FunASR + CosyVoice**，保存 GoFrame 地址（默认 `http://127.0.0.1:8000`），即可输入文字或点击 **语音** 录音、再次点击结束发送。豆包模式保存设置后可直接点 **开始通话** 持续说话，点 **结束通话** 释放麦克风；AI 说话时可直接插话。首次录音需允许浏览器访问麦克风。可用 **打断** 停止录音/回复/播放，**清空本机 Qwen 会话记忆** 清空连接内的记忆；新对话也会重建会话。后端及三个模型服务须先按 [本地语音部署说明](../backend/manifest/deploy/nvzhuang-voice-local/README.md) 启动。本机模式的文字每条最多 2000 字，录音最长约 64 秒；服务异常会显示错误。自动朗读开关同时控制本机合成音频的播放。旧对话里的“朗读”使用设备浏览器音色。

应用中语音状态面板的 TODO 以实际模型校验和服务健康状态为准；断网运行、MuMu/真人麦克风录音及主观音色试听应单独验证，不因代码测试通过自动完成。

未配置数据库时，TODO 勾选会原子保存到 `voice.root` 下的 `data/voice-todos.json`，重启仍保留；文件只包含固定任务 code 和完成布尔值，不包含聊天、Key、录音或用户配置。配置 MySQL 时继续使用数据库。存储损坏、数据库连接或写入失败会明确报错，不会假装保存成功或覆盖损坏文件。本机文件模式由一个后端进程使用，多进程部署应使用数据库。

语音转写完成前的“正在识别语音…”仅是界面提示，不进入历史或导出；识别失败需重新录音。等待麦克风授权时也可点击“打断”立即恢复文字聊天。录音不足 0.1 秒或近乎静音时不会发送。录音期间连接断开会停止设备；清空记忆未收到确认时会废弃旧连接，下一轮重新建立会话。录音时不能同时手动朗读历史回复。

清除记录或保存朗读偏好失败时，界面会保留原状态并提示错误，不会假装成功。清空图片 Key 字段并保存会移除该图片配置。导出文件按设备本地日期命名。

云端聊天每条最多 4000 字符。发送模型的上下文保留最近最多 20 条，并按 60 KiB 请求预算自动减少较早消息；单条长回复在后续上下文中最多发送 4000 字符，本机历史及导出保留完整回复。因此长对话中模型可能无法继续记住较早内容。保存新设置或移除 Key 会取消旧配置的活动请求，迟到结果不会写回当前聊天。

在 **陪伴角色** 中选择知夏或林溪，会一起切换角色人格、音色 ID、头像、初始服装、姿势和静态形象。旧语音连接会断开，浏览器按角色分别保留聊天记录。林溪的本机/豆包音色需要先按[语音说明](./VOICE-ENGINES.md#角色与音色)配置；未配置会提示，不会沿用知夏音色。云端文字模式的本机朗读取决于设备音色，可用同一设备声音搭配不同的语速/音高。

写真与聊天、录音独立：生成时仍可聊天或录音，工作室按钮会变为 **正在生成 · 取消**。主动取消或换角色、头像、服装、姿势时会中止旧写真，迟到的结果不会覆盖新选择。取消不能保证服务商未计费，页面不会自动重试。图片无效或无法显示时会给出提示并回到静态头像。

本机或云端文字输入以及最终语音转写会识别整句命令，例如“切换到林溪”“换成挥手打招呼”“换成二次元 12 号衣服”。衣服序号按当前图库全库排列，可在卡片上查看，也可使用如 `SPR-0001` 的精确编号。只有清单中的选择能生效，语音命令不会自动发起付费生图。

1. 打开页面右上角的设置，填入 OpenAI、DeepSeek、通义千问、OpenRouter 等兼容 OpenAI Chat Completions 的聊天服务地址、模型名和聊天 API Key。
2. 在侧栏点 **导出聊天记录** 可将当前设备保存的对话下载为 UTF-8 文本；导出在浏览器本地完成，不会上传。
3. 在右侧形象工作室点 **头像** 或 **衣服**，浏览本机内置模特库、真人服装库或动漫服装库；支持筛选和关键词/编号搜索，选择后立即保存在本机。
4. 选一个姿势，然后按 **生成这套穿搭**。首次使用还需要在设置的 **角色换装图像模型** 区域配置支持图像生成/编辑的模型及 Key。
5. 回复默认使用浏览器内置中文语音自动朗读；可关闭自动朗读，或点击任意回复下方的 **朗读** 再听一次。语音是设备本机合成，无需单独提供语音 API Key。

### 图像生成模型说明

聊天模型和图像模型是**两种不同能力**。DeepSeek 等文字聊天 Key 可以聊天，但一般不提供图像编辑能力；要生成真实的换装图片，请填写确实开放图像生成/编辑的模型 Key。界面提供 Gemini 图像模型和 OpenAI Images 兼容协议。点击“从上方聊天设置复制 Key”只会在本机表单中暂填，不会自动获得图像生成权限；请在保存前确认该 Key 能访问所选图片模型。使用不兼容的模型会显示清晰错误提示，不会伪装生成成功。

换装时，选中的模特图、服装图和姿势指令经本机代理发送给你选定的图像服务商，并消耗其配额。生成结果仅以浏览器临时图片显示，不上传图库、不保存进聊天记录，也不会持久写进服务端磁盘；可用同一姿势、头像和服装再次生成新结果。姿势变化会参与下一次图像生成提示词。

代理校验返回图片的编码、容器头与画布：单边最多 16384 像素，总像素最多 67108864。此检查不等同完整图片解码；图片无法显示时页面会回退头像。

## 隐私和安全

- 聊天和图片 Key、聊天记录、当前头像/服装/姿势保存在当前浏览器设备的 `localStorage`。豆包语音 Key 只保留在当前页面运行内存，刷新或关闭页面后清空；启动时会主动移除旧版本曾持久化的语音 Key。“移除本机 Key”会删除聊天/图片 Key、清空内存中的语音 Key 并取消活动请求，不删除后端环境变量。
- 本机模式录音仅发送给本机 FunASR/Qwen/CosyVoice；选择豆包语音后，录音会经本机后端发往豆包语音服务并产生其用量。豆包 Key 只在该 WebSocket 握手消息及后端内存使用，不能随页面指定第三方上游。
- 本机服务绑定 `127.0.0.1`，只有精确匹配的同源回环页面可向代理发起模型请求。模型服务地址禁止 URL 账号、密码、查询参数和片段；互联网服务必须 HTTPS。代理拒绝重定向。
- 聊天 Key 仅发送到填写的聊天服务；生图 Key 和已选图片仅发送到填写的图片服务。本机代理不会记录、不保存 Key 和聊天内容。
- 本机模式使用本地 CosyVoice，豆包模式使用豆包语音模型，均分段播放 WAV；云端文字聊天及历史回复“朗读”使用设备 Web Speech API，音色取决于浏览器和操作系统。
- 知夏是 AI 虚拟角色，不是真人；请勿在聊天里分享密码或其他敏感凭据。

## 当前可操作入口与诊断

启动后打开 **http://127.0.0.1:8787/**。页面是独立工作室；无需启动 UniApp 开发服务。新增模块在旧 Node 服务中会返回 404，更新源码后请关闭旧页面服务窗口再重新启动。后端更新也需要重新启动，诊断显示 `profile_aware=false` 表示仍在运行旧后端。

设置里可点击 **检查语音连接**，直接查看后端是否连通、本机三模型是否就绪，以及服务端是否配置豆包Key；它不读取或发送表单内的Key，不调用模型。命令行 `node doctor.mjs` 还可检查页面全部资源与角色握手。诊断只显示安全状态，不打印 Key、聊天或配置正文，也不调用付费模型。双击启动器遇到端口占用会先提示诊断，不会自动结束其他进程；空闲端口启动成功后会自动打开浏览器。

豆包 **开始通话** 使用本页当前运行会话中的语音 Key；后端环境已设置 Key 时也可留空。刷新或关闭页面后需要重新输入浏览器侧 Key。权限失败会明确停止，不会自动切换付费服务。不支持持续 PCM 的浏览器可使用 **按轮语音**。生成高清写真与通话分开，取消生图不会结束通话。

开发验收脚本 `node ../scripts/verify-companion-browser.mjs` 使用隔离浏览器和真实音频 API、模拟语音网络完成100轮；`node ../scripts/verify-companion-browser.mjs --local` 只请求本机 Qwen/CosyVoice 并验证实际 WAV 播放。它们不会读取已有浏览器的 Key 和聊天，合成设备不等同真人麦克风验收。
