# AI 女友 · 本次 30 轮完善与验收

本次 30 项均已完成检查、必要修复及对应验证。保留原有功能和界面风格，未新增依赖，也未调用真实付费图片或云端聊天服务。

## 1–20：聊天、设置、换装与语音

- [x] **第 1 轮：本机存储恢复。** 校验模型配置、聊天模式、后端地址及角色字段类型；丢弃过期生成 URL。损坏 JSON 和错误类型回归通过。
- [x] **第 2 轮：时间戳渲染。** 越界或非数值时间戳不再导致页面异常，内容仍可显示和继续聊天。
- [x] **第 3 轮：云端输入长度。** 4001 字符发送前拒绝，4000 字符边界可发送，避免后端拒绝后丢失输入。
- [x] **第 4 轮：上下文请求预算。** 按 UTF-8 序列化后的 60 KiB 预算减少较早上下文，并保留最新问题。
- [x] **第 5 轮：长回复后续兼容。** 本机保存完整回复，后续模型上下文中每条限制 4000 字符；9000 字符历史后继续发送验证通过。
- [x] **第 6 轮：设置保存一致性。** 批量写入失败恢复原设置，不关闭设置窗口或启用部分新值；恢复失败有明确提示。
- [x] **第 7 轮：切换设置取消请求。** 保存新模式和配置时取消旧请求，旧结果与清理回调不影响新回合。
- [x] **第 8 轮：移除 Key。** 先取消活动任务、清空内存和表单，再尝试分别移除聊天与图片 Key；不把浏览器删除失败报告为成功。
- [x] **第 9 轮：图片默认模型。** OpenAI 图片模型在协议切换、空字段保存和重开设置时统一为 `gpt-image-2`。
- [x] **第 10 轮：重复生图防护。** 共用图库加载请求，加载完成后复查任务状态，并发点击仅产生一次图片请求。
- [x] **第 11 轮：取消与迟到图片。** 取消不接受旧图片、不创建预览 URL，也不解锁新聊天；移动工作室内提供可点击的取消按钮。
- [x] **第 12 轮：选择一致性。** 生成期间锁定头像、服装和姿势，已打开的图库或程序化事件不能更改当前生成目标。
- [x] **第 13 轮：图片异常响应。** 对空结果、非法 Base64、非支持 MIME 和非法 JSON 显示可恢复错误。
- [x] **第 14 轮：预览生命周期。** 替换、切姿势或图片加载失败时释放生成 URL；加载失败回退所选头像，生成 URL 不保存到浏览器持久配置。
- [x] **第 15 轮：图库重试与筛选。** 首次加载失败后可重试，头像面部/全身、真人/动漫服装筛选仍可正常使用。
- [x] **第 16 轮：录音质量边界。** 小于 0.1 秒或近乎静音的录音在本机拒绝，不发送、不保存假转写。
- [x] **第 17 轮：拒绝麦克风授权。** 授权失败后释放启动锁，可立即改用文字；迟到授权仍会释放设备。
- [x] **第 18 轮：回合隔离。** 时间戳加单调序号，同一毫秒内的回合 ID 也不重复；旧字幕及结束事件不会结束新回合。
- [x] **第 19 轮：清空记忆与播放。** 清空前停止当前和排队音频；等待确认期间拒绝重复重置和新文字回合。
- [x] **第 20 轮：朗读互斥。** 浏览器朗读与本机 WAV 不叠加，开始新本机回合或录音会停止旧朗读。

- 本次没有真人麦克风录制、主观音色试听、真实付费云端聊天或生图验收；相关协议使用模拟上游结果验证。

- 文件待办使用单个后端进程；多进程部署应配置数据库。本次没有真实 MySQL 环境集成验收。
