# AI 女友 · 第二批 30 轮完善与验收

本批延续第一批 30 轮，没有覆盖第一批记录。每项均有新场景的代码核查或回归证据；确认原实现正确的场景保留源码，只增加验证。未新增依赖，未调用真实付费聊天或生图 API。

## 前端协议与会话恢复（1–11）

- [x] **第 1 轮：控制消息结构。** WebSocket 的 null、数组和标量控制消息不会触发属性访问异常；之后合法回合仍能完成。
- [x] **第 2 轮：文本边界。** 拒绝非字符串增量、累计超过 20000 字符的回复及空白/非字符串/超过 2000 字的识别结果；即时结束等待，不保存伪回复。
- [x] **第 3 轮：二进制分段边界。** 音频只能出现在已开始分段内，重叠开始和分段外二进制立即报错并取消。
- [x] **第 4 轮：分段结束。** 缺少开始、空分段或 turn.end 前未结束的音频不能被报告为成功回合。
- [x] **第 5 轮：服务端取消。** 收到 assistant.cancel 后立即释放等待、计时器与播放，不再等到 120 秒超时；迟到回复不会写入。
- [x] **第 6 轮：重置超时。** session.reset 未确认时废弃旧连接，下一轮建立新会话，避免继续使用状态不确定的记忆。
- [x] **第 7 轮：重置与录音互斥。** 等待清空记忆确认期间不能打开麦克风。
- [x] **第 8 轮：录音断线。** 连接关闭后立即停止轨道、AudioContext、处理器和录音计时器，恢复输入并显示已断线状态。
- [x] **第 9 轮：设备初始化失败。** 新增 AudioContext 构造和 resume 失败回归；确认原有释放逻辑能够回收已获得的轨道，未改动该正确行为。
- [x] **第 10 轮：录音与手动朗读。** 准备或进行录音时拒绝历史朗读，防止扬声器内容混入录音。
- [x] **第 11 轮：迟到朗读回调。** 旧 utterance 的结束/错误不再覆盖当前朗读状态；手动朗读期间不叠加新到的本机 WAV。关闭播放不破坏合法音频传输分段。

## 本机数据与操作结果（12–20）

- [x] **第 12 轮：首次语音界面。** 识别占位显示时隐藏欢迎页，但不创建可导出的假历史。
- [x] **第 13 轮：云端空结果。** 成功或失败状态下返回 null 时均显示可读错误，不再出现原始属性访问异常。
- [x] **第 14 轮：空白历史。** 忽略已保存的空白消息，不把它们发送给云端接口。
- [x] **第 15 轮：历史元数据。** 只恢复 role、content 和时间戳，去掉旧 error/pending/retryable 等界面标记及无关字段，保留有效正文。
- [x] **第 16 轮：清除保存失败。** 空历史写入失败时，界面与原记录都保持，不再呈现清除已成功的假象；存储恢复后可正常清除。
- [x] **第 17 轮：导出失败。** 下载被拒绝时提示错误并回收临时 Blob 地址；导出文件名使用设备本地日期。
- [x] **第 18 轮：朗读偏好保存。** 保存失败时保持原开关、aria-pressed 和正在播放的音频，不在刷新后悄悄反转偏好。
- [x] **第 19 轮：图片 Key 清空。** 清空图片 Key 字段并保存后，确实删除对应本机图片配置，重新打开设置仍为空。
- [x] **第 20 轮：输入反馈。** 本机模式按 Unicode 字符显示 2000 限制，云端按 4000 单位计数；标记超限、清空后恢复高度，输入更新不能禁用活动请求的停止按钮。

## 服务端与后端（21–28）

- [x] **第 21 轮：规范 Origin。** 拒绝包含路径、账号、查询或片段的伪 Origin，以及 Host 不匹配来源；拒绝前不会接触模型上游。
- [x] **第 22 轮：原始请求地址。** 对原始 URL 中的片段和非法百分号转义返回受控 JSON 400，不让 URL 解析器静默忽略它们；合法请求和健康检查仍可用。
- [x] **第 23 轮：异常上游结构。** 新回归确认现有实现可处理 HTTP 200 的 null、布尔、数值、字符串、数组及错误 schema，返回受控 no-store JSON 502，不泄露上游私有头。误标 text/plain 的有效 JSON 兼容行为保留。
- [x] **第 24 轮：握手校验。** WebSocket 客户端必须使用版本 13、规范的 16 字节 Base64 Key；错误版本返回 426，错误 Key 返回 400。上游 Sec-WebSocket-Accept 错误时返回 502 并回收连接。
- [x] **第 25 轮：图片结构与画布。** 增加 PNG 头部/结尾、JPEG SOF/SOS 尺寸及 WebP 容器/VP8、VP8L、VP8X 画布检查；拒绝零尺寸、损坏容器、单边超过 16384 或总像素超过 67108864 的结果。真实小尺寸格式夹具通过。
- [x] **第 26 轮：握手前音频。** Go 后端在 session.start 前拒绝二进制及 input.end，不保留握手前录音，也不触发模型处理。
- [x] **第 27 轮：超限录音尾片。** 超过 2 MiB 后整轮保持拒绝，尾片不能重新成为可识别的新录音；结束/取消/重置后下一轮可恢复。
- [x] **第 28 轮：合成中回合失效。** 新增 TTS 请求阻塞期间并发 Begin、Reset、取消 Context 的 fake HTTP 回归；原 session 提交机制正确，未修改其源码。未完成回合不写入记忆，Reset 清空，其他取消保留先前成功记忆。

## 实际运行验收（29–30）

- [x] **第 29 轮：真实浏览器。** 独立 Edge 验证 2000 个 emoji 的本机计数、超限 aria-invalid、模拟写入失败后记录保留、恢复后清空及输入高度重置；320、375、768、812、1024、1440 六种宽度无横向溢出。导航、Escape、弹窗、减少动效与 WAV 播放继续通过。
- [x] **第 30 轮：综合与运行版本。** 前端 61 项、服务端 21 项测试通过，Go 全量测试、vet 和构建通过。业务服务已更新。真实代理链路得到 14 字转写、33 字回复、15 段 WAV、352020 字节音频，session.reset 确认成功。原 6 项应用 TODO 重启后仍保持完成。

## 范围与限制

- 这 30 项包含必要修复和确认原行为正确的新回归，不代表 30 个独立新功能或 30 个均需改源码的缺陷。
- 浏览器使用独立测试资料目录及允许自动播放的测试参数；不接触用户浏览器资料，验收后关闭测试浏览器。
- 真人麦克风主观试听、真实付费模型和真实 MySQL 集成不在本次已验证范围。
- 图片检查验证容器头和画布上限，不等同完整解码或视觉质量保证；浏览器显示失败仍会回退。
- 本机历史和 Key 仍保留于浏览器；待办文件只保存固定任务的布尔值。取消本机请求不保证服务商未计费。
