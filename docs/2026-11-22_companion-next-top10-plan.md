# AI 陪伴系统下一批 10 项功能计划

日期：2026-11-22

每项功能独立实现、测试、提交并推送：

1. H5 扬声器/耳机输出设备选择与本地偏好。
2. 通话质量指标：时长、重连次数、拥塞次数与质量提示。
3. 通话前自检：网络、端点、麦克风能力和角色音色配置。
4. 本地对话记录按关键词搜索。
5. 本地对话记录 JSON 导入与严格校验。
6. 对话记录自动保留期限（7/30/90 天或永久）。
7. 高清写真任务队列，限制并发和队列长度。
8. 当前运行期间的写真结果历史与失败重试。
9. 角色外观预设的保存、应用和删除。
10. 陪伴数据隐私中心：统计并一键清除角色、记录和设备偏好。

共同约束：不持久化音频、API Key、Token 或第三方任意 URL；每项功能均补充自动化测试并通过前后端门禁。
