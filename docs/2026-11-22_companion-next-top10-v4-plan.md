# AI 陪伴第四批高优先级完善计划

日期：2026-11-22

本批继续坚持“本机可验证、隐私优先、每项独立提交和推送”。SeedDuplex 真实账号、真人麦克风和 Android 真机验收仍保留为人工验收项，不以模拟测试冒充完成。

## 执行清单

1. [x] 为 H5 页面标题提供安全默认值，消除未配置环境变量时的构建告警。
2. [x] 修复 H5 备份文件选择器取消后可能一直等待的问题。
3. [x] 支持直接浏览最近的本地对话记录，无需先输入搜索词。
4. [x] 支持仅查看已收藏的本地对话。
5. [x] 支持仅导出已收藏对话，减少不必要的私密内容暴露。
6. [x] 删除单条对话后提供当前页面内的撤销机会。
7. [x] 支持一键清理未收藏对话，并保留收藏记录。
8. [x] 支持复制不含对话正文的本次通话摘要。
9. [x] 将本机麦克风和扬声器试音结果纳入通话前自检提示。
10. [x] 展示白名单分类的本地陪伴存储占用，不解析或展示存储值。

## 完成标准

- 每项功能具有针对性自动化测试或构建验证。
- 每项功能独立执行安全扫描、后端 `go test ./...`、`go vet ./...`。
- 每项功能使用 Conventional Commits 独立提交并推送。
- 不提交真实密钥、真实配置、用户内容、设备标识或个人绝对路径。
