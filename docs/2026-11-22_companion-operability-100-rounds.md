## 可重复运行

```powershell
# 在 girlfriend 目录
node doctor.mjs
node --test app.test.mjs duplex-session.test.mjs doctor.test.mjs health.test.mjs
node server.test.mjs

# 在项目根目录
node scripts/verify-companion-browser.mjs
node scripts/verify-companion-browser.mjs --local
node scripts/verify-companion-local.mjs --self-test
node scripts/verify-companion-local.mjs
```

浏览器脚本使用隔离临时profile，不读取现有浏览器Key/历史。默认模式仅模拟网络，使用真实音频设备API；`--local`只调用已有本机模型，不发云端请求。截图保留在系统临时目录供本机查看，本模型无法解读截图内容，布局使用DOM断言验证。
