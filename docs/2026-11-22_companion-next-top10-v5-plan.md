# AI 陪伴第五批高优先级完善计划

日期：2026-11-22

本批继续执行隐私优先、自动化可验证、每项独立提交并推送。真实 SeedDuplex 账号、真人麦克风和 Android 物理设备验收仍不以模拟测试代替。

## 执行清单

1. [x] 后端服务地址仅允许远程 HTTPS 或受控本机开发地址。
2. [x] 客户端图像模型端点拒绝明文远程地址、凭据和查询参数。
3. [x] 严格清洗本地设置结构并移除旧版持久化语音 Key。
4. [x] 在设置页增加不产生付费请求的语音后端配置自检。
5. [x] 对话保留期限清理时始终保留用户收藏记录。
6. [x] 删除造型预设后支持当前页面内撤销。
7. [x] 阻止重复的造型预设名称，降低误选风险。
8. [x] 支持主动释放当前高清写真及其大体积内存数据。
9. [x] 对话、预设和角色偏好变化后自动刷新本地占用统计。
10. [x] 支持将全部或收藏对话下载为版本化 JSON 文件。

## 完成标准

- 每项具有针对性测试，并通过 TypeScript 与 ESLint 校验。
- 每次提交前执行敏感信息扫描、后端 `go test ./...` 与 `go vet ./...`。
- 每项使用 Conventional Commits 独立提交并推送。
- 不提交真实 Key、用户对话、生成图片、设备标识或本机私有配置。
