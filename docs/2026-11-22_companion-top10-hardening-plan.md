# AI 陪伴系统前 10 项完善计划

日期：2026-11-22

目标：在不改变既有 SeedDuplex、本地语音和形象生成协议的前提下，补齐日常使用最影响稳定性、可诊断性与隐私控制的十项能力。

## 功能范围

1. 监听在线/离线状态，断网时停止盲目重连。
2. SeedDuplex 非主动断开后自动重连。
3. 使用有上限的指数退避，避免连接风暴。
4. 提供手动立即重试和取消重连。
5. 枚举可用麦克风并显示安全标签。
6. 本地保存首选麦克风，重连时继续使用。
7. 监听设备插拔，设备消失时安全回退默认输入。
8. 展示系统回声消除、降噪和自动增益的实际状态与建议。
9. 按角色保存有界文本对话记录，并支持导出、单角色清除和全部清除。
10. 提供统一运行诊断面板，集中展示网络、连接、设备、回声处理和本地记录状态。

## 安全与隐私约束

- 只在浏览器或 App 本地保存设备偏好与文本记录。
- 不保存音频、API Key、Token、后端响应头或服务端地址中的凭据。
- 对话记录设置条数和字符上限；损坏或超限的本地数据自动丢弃或裁剪。
- 自动重连只在用户主动开启持续通话后生效；离开页面、手动结束或切换角色后立即取消。

## 验收门禁

- 新增模块具有单元测试，覆盖退避、取消、设备回退、存储边界、导出和清除。
- `pnpm type-check`、`pnpm lint`、`pnpm test:run` 全绿。
- Android 工程在可用 JDK/SDK 环境下通过 Gradle 编译检查。
- 后端 `go test ./...` 与 `go vet ./...` 全绿。
