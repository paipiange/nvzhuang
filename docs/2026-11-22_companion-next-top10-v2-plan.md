# AI 陪伴系统第二批 10 项完善计划

日期：2026-11-22

每项功能独立实现、测试、提交并推送：

1. 写真任务保存点击时的角色与造型快照，切换造型后不串任务、不覆盖当前形象。
2. 当前运行期间的写真结果画廊，可重新查看最近成功结果且不持久化图片。
3. 一键复制脱敏诊断报告，只包含状态、计数、错误码和能力信息。
4. 通话回合延迟指标：连接、首字幕、首音频和回合完成耗时。
5. 有界诊断事件时间线，不记录字幕、音频、Key 或请求正文。
6. 本地保存首选语音引擎，不保存 SeedDuplex Key 或任意服务地址。
7. 通话前麦克风试音与输入电平判定，不上传或保存试音音频。
8. 导出完整陪伴数据备份，排除凭据、音频、设备 ID 和第三方 URL。
9. 严格校验并恢复陪伴数据备份，支持合并与替换模式。
10. 角色外观预设重命名与复制，继续执行数量和字段白名单限制。

共同约束：不自动调用可能计费的云服务；不把自动化测试描述为真实账号、真人麦克风或物理设备验收。
