# 本地语音验收记录

本记录区分真实设备采集、合成测试输入、模型推理与主观试听。测试音频通过不等于真人口播或音色自然度已经验收。

## 本轮实现

- H5 / MuMu 显示实际输入 RMS 和峰值 dBFS。仅对整轮近数字静音给出本地提示并取消上传；正常轻声和短暂有效峰值仍进入识别。原生 App 没有实时 PCM 采样时明确说明能力限制。
- 本地 TTS 以约 0.5 秒、24kHz 单声道的独立 WAV 片段发送，不再等待整段合成完成。前端 FIFO 播放，等待生成结束及队列播放完才允许下一轮。每轮累计音频限制 32 MiB；取消、后台、断开和错误会清理队列与资源。
- 每个 WebSocket 连接独立保存最近 6 轮、最多 6000 Unicode 字符的成功生成对话，仅在内存使用。生成过程中取消、失败及过期回合不写入历史；音频已全部生成并发送后，再打断播放不会回滚已完成的历史。页面提供带后端确认的“清空会话记忆”，重连也会清空。
- 模型就绪检查核对固定版本关键文件、GGUF 基础头部与预期长度；缺失、空文件和错误健康响应不会显示就绪。页面显示服务加载、依赖或端口问题提示。部署日志解析限制为 4 KiB，不将原始日志或凭据传到 App。
- 新增可复现的本机验收脚本 `scripts/verify-local-voice.mjs`，接受授权的 16kHz 单声道 PCM16LE，限制回环连接，输出格式检查、耗时与计数，不输出对话正文。

## 真实麦克风与音频质量

- Windows 麦克风隐私策略为允许，但本机仅枚举到两个在线音频输出端点，没有在线物理麦克风输入；部分麦克风显示未插入，蓝牙录音设备未连接。MuMu 虚拟内置麦克风存在，不代表宿主连接了可用麦克风。
- 新版 MuMu 实际录音的 RMS 和峰值为 **-100 dBFS**。页面在录制中提示检查宿主设备；结束时明确提示“本轮录音未发送”，回到可再次录音状态。没有把静音输入视为成功识别。
- 上轮已验证真实录音启动、未静音及停止事件，按 Android Home 后采集立即停止；本轮保留这些资源清理行为。
- 三句通用合成音频均未出现波形削波。经 FunASR 重新识别，去除标点后的字符相似度为 **100%、89%、100%**；这些是内容清晰度的客观样本，不是人工评定的字词准确率或声纹相似度。
- 样音可用于人工试听；不包含原始参考录音或真人测试录音。主观自然度、相似度与舒适度仍需人耳判断。

## MuMu 分段播放

- 新版 H5 已构建并装入独立 `.debug` Android 包，保留正式包数据。
- 使用明确标记的合成中文 MediaStream 测试输入，实际经过 App、GoFrame、FunASR、Qwen、CosyVoice 和 Android 播放通道。
- 一次完整回合首声约 **4.17 秒**；**14 个片段全部播放结束**，播放墙钟时间约 **7.05 秒**，片间衔接约 **3～9 毫秒**。这是本机样本，不是性能承诺。
- 实机点击“清空会话记忆”收到确认，字幕清除，页面保持空闲。测试结束后已恢复真实麦克风 API，没有在产品代码中保留输入替换。
- 对比上轮等待整段音频的三个 App 样本（5.53、4.35、4.66 秒）时，应考虑模型回复长度与采样差异；不据此声称固定百分比提速。模拟流测试另已证明首片在上游 HTTP EOF 之前送达。

## 连续与异常测试

- 新版严格验收脚本完成 **25 个成功回合**，另有 **1 次中途取消**（确认约 102 毫秒）和 **3 次重连**。每轮收到 10～18 个完整 RIFF/WAV 片段，格式、长度、开始/结束闭合均通过。
- 暂停本机 FunASR 容器后，后端返回 `voice_pipeline_failed` 错误；测试结束立即恢复容器，并确认未留下暂停状态。恢复后额外一轮严格验收通过：识别约 **445 毫秒**，首音频约 **4.31 秒**，完整生成约 **5.20 秒**，14 个音频片段格式正常。
- 新版采样中识别约 **424～532 毫秒**，文本回复约 **506～632 毫秒**，首个 WAV 片段约 **3.45～4.39 秒**，完整生成约 **3.46～8.14 秒**。网络首片耗时与 Android 真正开始播放的耗时分别测量，不能混用。
- 改造前的真实模型基线完成 **22 个完整回合、3 次中途取消、2 次重连**，取消和重连后均能继续。整段音频返回耗时约 **3.63～7.04 秒**。
- 真实记忆测试初次运行时，同连接成功回忆“蓝色”，reset 后不再提供该偏好，但一次新连接回复仍出现“蓝色”。单元测试确认新连接请求不含旧历史。补充未提供的信息不得猜测后，真实模型复测通过：同连接能回忆蓝色；reset 收到确认后回答不知道；断开重连后也回答不知道。四轮均有非空文本与音频。模型回答仍可能有随机性，不能把一次复测当作绝对无幻觉保证。
- 模拟测试覆盖首片提前发送、奇数字节、超限、错误采样率、取消关闭上游、历史隔离和裁剪、reset、失败不提交，以及旧回合错误在 reset 后被丢弃。
- 前端覆盖 FIFO 顺序、延迟 Blob 解码、取消后的旧回调、生成结束早于播放结束、累计上限、播放错误、清空确认与超时、静音阻断和轻声放行。

## 离线验证范围

- 前一轮分别验证了 Qwen、FunASR 断公网直连后仍可推理；CosyVoice 在只有回环网卡的网络命名空间中完成离线冷启动与合成，冷启动约 97.22 秒。
- 本轮在同一时间保持 TTS 无公网命名空间及 Qwen/FunASR 公网路由隔离守护，真实后端完成 **5 个连续回合**，耗时约 **4.83～6.10 秒**；前后检查 Docker 隔离守护仍在运行，TTS 隔离进程确认公网 IPv4/IPv6 直连失败。后端仍通过本地中继访问模型，未断开整台机器。
- Docker 路由已恢复且没有残留测试容器。一次性验收脚本的 TTS 恢复守护卡住，已人工确认并清理隔离测试进程，再重启正常 TTS；不将恢复脚本视为已验收的产品部署功能。这些临时隔离脚本不纳入产品提交。
- Docker 内置 DNS 代理未单独隔离，业务后端及宿主机也未整机断网，因此该测试不等同于物理拔网或证明所有辅助进程绝无网络访问。
- 可选 SeedDuplex 与 Open-LLM-VTuber 不属于本地三个模型的离线验收。当前 H5 SeedDuplex 仍按轮发送录音，没有持续麦克风全双工采集。

## 仍需硬件或人工参与的验收

- 连接有效物理麦克风后，真人说话并核对识别、播放、打断与多轮体验。当前无有效宿主输入，无法通过软件修改替代这项验收。
- 人工试听音色自然度、相似度和语速。自动削波检测及 ASR 回环只提供辅助证据。
- 关键文件与基础格式检查不等同于密码学哈希或完整模型权重校验；切换下载版本需同步检查清单与预期长度。
